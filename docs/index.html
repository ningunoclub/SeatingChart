Features

🪑 Smart seating

Generate truly random charts or use constraint-aware randomized backtracking to honor your rules.

🏫 Class management

Add classes and students, attach photos, set gender, and keep everything organized in one place.

📐 Visual room editor

Click-and-drag grid canvas with blackboard orientation, quick-setup sheet, and disabled seats.

🎲 Name picker

Draw names without replacement and show the result in an always-on-top overlay window.

👥 Group builder

Split a class into balanced teams by group size or max per group, with optional gender quotas.

📄 Export & share

Print or save PDFs and import/export .seatingchart bundles with photos included.

🖥️ Presentation mode

Fullscreen view optimized for projectors and AirPlay displays.

🔒 Fully offline

No network, iCloud, or analytics traffic. All data stays on your Mac.

Install

  1. Click Download latest release above to get the zip file.
  2. Double-click the zip to extract Seating Chart.app.
  3. Drag Seating Chart.app into your /Applications folder.
  4. Open it from Launchpad or Finder.
The app is ad-hoc signed, so macOS may show a Gatekeeper warning the first time you open it. If that happens, right-click the app and choose Open, or go to System Settings → Privacy & Security and click Open Anyway.

Requirements: macOS 14.0 (Sonoma) or later. The UI is available in English and German and follows the system language automatically.

All data is stored locally in ~/Library/Application Support/SeatingChart/. Student photos are kept in a local Images/ folder and are never transmitted.

SeatingChart is provided as-is for personal or classroom use. Source code on GitHub.
